# Taskra — Project Context

Taskra is a Solana-native trust and settlement layer for verifiable digital work.

Core MVP:
Client → Technical Task → USDC Escrow → Developer → GitHub Evidence → Verification → Settlement → Reputation.

Hackathon objective:
Build one complete, real economic workflow that a judge can execute and independently verify on Solana.

Primary network:
Solana Devnet during development/demo unless deployment configuration explicitly changes this.

Primary asset:
USDC.

Primary evidence path:
GitHub pull request / repository evidence.

## Non-goals

Do not build:
- DAO
- governance token
- NFT system
- token speculation
- social feed
- chat system
- mobile app
- multi-chain support
- AI marketplace
- AI-agent framework
- complex arbitration protocol
- complex reputation mathematics
- full Fiverr/Upwork feature set

## Priority

1. Correctness
2. Security
3. Real Solana settlement
4. Complete economic workflow
5. Evidence verification
6. Reputation
7. Reliability
8. UX polish
9. Future roadmap
